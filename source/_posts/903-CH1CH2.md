### 深度学习模型 = 计算流图

[补] 深度学习模型（DL Model）可表示为一个**计算流图（计算图）**：数据从输入出发，依次经过若干**算子**（OP，Operator——如矩阵乘、加偏置、激活、Softmax），产生一个或多个输出。算子开发需同时考虑**矩阵的算法**与 **GPU/NPU 的结构**。

{% mermaid %}
graph LR
    X[输入 X<br/>特征向量] --> OP1[OP1<br/>算子] --> OP2[OP2<br/>算子] --> OP3[OP3<br/>算子]
    OP3 --> P1[P1<br/>输出1]
    OP3 --> SM[Softmax<br/>算子]
    SM --> P2[P2<br/>概率输出]
{% endmermaid %}

**全连接算子是什么**：
[补] **全连接层/算子**（Fully Connected，FC，也称 Dense）：输出层的每个神经元与上一层**所有**神经元相连。
- 数学形式：$\mathbf{y} = W\mathbf{x} + \mathbf{b}$——一次**矩阵乘法**（W：权重矩阵）+ 偏置加法，通常后接激活函数（如 ReLU）
- 计算图中的角色：把输入特征做全局线性变换，常用于网络末端做分类/回归
- 实现视角：FC 的核心是**通用矩阵乘（GEMM）**——为什么"算子开发要考虑矩阵算法和 GPU 结构"：矩阵乘的算法选择（分块、访存局部性）与硬件结构（核数、缓存、数据搬运）直接决定算子的实际性能

## 机器学习

**定义**：机器能够从人类经验中**学习**，并自动提升性能。
**三要素**：任务 T、性能度量 P、经验 E
> 形式化描述：对于某类任务 T 和性能度量 P，如果一个计算机程序在 T 上以 P 衡量的性能随着经验 E 而自我完善，那么就称这个计算机程序在从经验 E 学习。

### 任务（Task）

**样本**：[补] 由 n 个特征构成的向量，一般用 $\mathbf{x} \in \mathbb{R}^n$ 表示（原笔记记作"x 属于号 R^n"，现更正：$\mathbf{x}$ 为 n 维实向量，$\in$ 表示"属于"，$\mathbb{R}^n$ 为 n 维实向量空间）

**数据集**：训练集 / 测试集

**任务类型**：
1. 分类——这只猫还是狗？
2. 回归——这个西瓜的价格？
3. 聚类——这个水果市场里卖了几种口感的西瓜
4. 异常检测

> 大模型的生成（单次生成 token）本质是**分类**问题；量化交易→预测股票价格→回归问题。

### 性能度量

[补] 二分类混淆矩阵（T = Total 总样本数 = TP + FP + TN + FN）：

| 混淆矩阵 | 预测为正 | 预测为负 |
| ---- | ---- | ---- |
| **实际为正** | **TP**（True Positive，真正例） | **FN**（False Negative，假反例 / 漏报） |
| **实际为负** | **FP**（False Positive，假正例 / 误报） | **TN**（True Negative，真反例） |

- **准确度**（Accuracy）A：$A = \dfrac{TP+TN}{T}$——所有样本中猜对的比例
- **查准率**（Precision）P：$P = \dfrac{TP}{TP+FP}$——预测为正的里面有多少个是真正正确的
- **查全率**（Recall）R：$R = \dfrac{TP}{TP+FN}$——实际为正的里面有多少个被预测出来了
- **F-measure**：[补] 查准率与查全率的**调和平均**：$F_1 = \dfrac{2PR}{P+R}$（只有当 P 和 R 都高时 F₁ 才高）；一般形式 $F_\beta = \dfrac{(1+\beta^2)PR}{\beta^2 P + R}$（β>1 时更侧重查全率）
- MSE / RMSE：回归任务的误差度量

### 学习范式

```
机器学习
├── 有监督学习：给定输入样本 x 和相应标签 y，估计 p(y|x)
├── 无监督学习：估计概率分布，或做聚类
├── 半监督学习
├── 强化学习：主要用于决策
└── 自监督学习
```

### 线性回归模型

[补] 模型假设：$\hat{y} = \mathbf{w}^\top\mathbf{x} + b$（训练 = 找到使损失最小的 w 与 b）
目标：最小化训练集上的均方误差：$\min \mathrm{MSE}_{train} = \dfrac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$

**其中涉及的线性代数知识点**：
1. **向量与内积**：$\hat{y}_i = \mathbf{w}^\top\mathbf{x}_i + b$ 本质是权重向量与样本向量的**内积**（衡量两向量在对齐方向上的分量）
2. **矩阵化表示**：把 n 个样本堆成矩阵 $X$（n×d），则 $\hat{\mathbf{y}} = X\mathbf{w} + b\mathbf{1}$，MSE 可写为 $\frac{1}{n}\|\mathbf{y} - X\mathbf{w}\|_2^2$（$\|\cdot\|_2$ 为 L2 范数/向量长度平方）
3. **求导与正规方程**：对 w 求梯度 $\nabla_w = -\frac{2}{n}X^\top(\mathbf{y} - X\mathbf{w})$，令梯度为零解得**正规方程**：$\mathbf{w}^* = (X^\top X)^{-1}X^\top\mathbf{y}$
4. **可逆性条件**：$X^\top X$ 可逆需要 特征数 < 样本数 且特征间无多重共线性；若不可逆或病态，则退而用梯度下降迭代求解
5. **为何常用梯度下降而非直接解方程**：样本/特征规模大时求逆 $O(d^3)$ 代价过高

### 梯度下降

- 沿损失下降最快的方向（**负梯度**方向）迭代更新参数
- 问题：可能只收敛到**局部最优**；学习率怎么设置、导数怎么求（留待反向传播）
- **随机梯度下降**（SGD）：每次用少量（随机）样本估计梯度——计算量小、且随机性有助于跳出局部最优

### 过拟合与欠拟合

- **过拟合**：模型在训练集上误差很低、测试集上误差很大
  - 原因：训练集规模小 / 模型过于复杂
- **欠拟合**：模型不能很好地拟合训练数据集，训练集上误差就比较大

**解决方案**：
- 增加数据集的规模
- **正则化目标**——参数惩罚项：
  - [补] **L2 正则 / 权重衰减（Ridge）**：在损失上加 $\lambda\|\mathbf{w}\|_2^2 = \lambda\sum_j w_j^2$，惩罚数值大的权重，迫使各权重整体变小、模型变"平滑"。例：用 9 次多项式拟合少量样本会过拟合（系数极大、剧烈震荡），加大 λ 后高次项系数被压小，测试误差显著下降
  - [补] **L1 正则（Lasso）**：加 $\lambda\|\mathbf{w}\|_1 = \lambda\sum_j |w_j|$，使部分权重被压到精确为 0，产生**稀疏解**，可作特征选择
  - [补] λ 控制正则强度：λ 太小≈不过正则（仍过拟合），λ 太大则欠拟合
