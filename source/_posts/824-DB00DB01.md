# Ch.1 数据库系统概述

> 📌 课堂标注（章节重要性）：`235 importance` · `67 介绍`

## 数据与数据的特性

**数据**（data）：具有一定语义含义、可被记录下来的已知事实；在计算机中表示为有一定格式（或结构）的符号串【db01 P4】
**信息**（information）：用于反映现实世界事物的物理状态，向人们提供已知的、客观存在的事实和知识

> **数据是信息的载体，信息是数据的内涵**——现实世界经"抽象"进入计算机世界（数据），数据"蕴涵"信息【db01 P5】

**数据的特性**【db01 P6】：
1. 数据表现的**多样性**（常用数据、多媒体数据、抽象数据）
2. 数据的**可构造性**：型（type）/值（value）、数据类型、数据结构、数据模式（schema）
3. 数据的**挥发性/持久性**（transient / persistent）
4. 数据的**私有性/共享性**（private / share）
5. 数据"量"的表示：少量 / 大量 / **海量**

> <mark>数据的"量变"可能引起数据的"质变"</mark>——"量"是衡量与区别数据的重要标志【db01 P6】
> 数据特性在变化：量 少→多→海量；结构 简单→复杂；服务范围 私有→共享；软件中的地位 附属（以程序为主体）→主导（以数据为中心）【db01 P7】

## 数据库 / DBMS / 数据子语言

**数据库**（Database，DB）：**数据集合**，具有统一的结构形式并存放于统一的存储介质内，由多种应用数据集成，可被应用共享【db01 P9】
> 通俗理解（课堂）：可以理解为存储数据的文件。关键词：**结构化、集中存储、数据共享**。

**数据库管理系统**（Database Management System，DBMS）：一种**管理数据库的系统软件**，在文件管理系统的基础上发展而来【db01 P11】
> 通俗理解（课堂）：用户与操作系统之间的数据管理软件。
> 区别于其他软件系统的特点：① 能管理**持久性**数据 ② 能对**大量**数据有效存取 ③ 能为众多使用者提供同一数据（**共享**）
> 作用：是数据库应用程序与数据库的**接口**；在保证数据安全可靠的同时，提高数据库应用的简明性与方便性
> 功能：数据组织（Definition）、数据操纵（Manipulation）、数据维护、数据控制及保护、数据交换、数据服务、数据字典【db01 P12】

**数据子语言**（data sub-language）【db01 P13】——SQL 语言由三类组成：
- **DDL**（Data Definition Language，数据定义语言）：负责数据的**模式定义**与数据的物理存取构作
- **DML**（Data Manipulation Language，数据操纵语言）：负责数据的**操纵**，包括查询及增、删、改
- **DCL**（Data Control Language，数据控制语言）：负责**完整性、安全性**的定义与检查，以及并发控制、故障恢复

数据子语言的使用方式【db01 P14】：
- **交互式命令语言**：终端上即席操作，又称自含型/自主型语言
- **宿主型语言**：嵌入 FORTRAN、COBOL、C/C++、Java 等高级过程性语言中

## DBA / DBS / DBAS

**数据库管理员**（DBA，Database Administrator）：对数据库进行规划、设计、维护、监视的**专职人员**【db01 P15】
- 数据库设计，建立与调整
- 数据库维护
- 改善系统性能，提高系统效率

**数据库系统**（DBS，Database System）：以对海量的、具有复杂数据结构的、可以持久保存的、可供多用户共享的数据进行统一管理为目标的**计算机系统**【db01 P16】
**DBS 的组成**：数据库 + 数据库管理系统 + 数据库管理员 + 软件平台（操作系统、语言、数据库应用开发工具、通用的数据库访问接口）+ 硬件平台

**数据库应用系统**（DBAS，Database Application System）：利用数据库系统作应用开发所构成的**集成化的独立运行系统**【db01 P17】
**DBAS 的组成**：数据库系统 + 应用软件 + 应用界面 + 用户

## 数据库用户

1. **最终用户**（End users）：终端查询用户（Casual users）/ 应用程序的使用者（Naive users）
2. **应用程序开发人员**（Application programmers）
3. **数据库管理员**

> 三类用户都需要掌握与其工作相关的数据库技术【db01 P19】

## 数据库系统的发展历史

- 讲义脉络：文件系统 → DBMS 萌芽（'60s）→ 层次/网状模型（'70s）→ 关系数据库商用兴起（'80s）→ 成熟与新技术【db01 P22–28】
- 课堂强调：**空间数据库、分布式数据库**——这两个现在还在发光发热

## 数据库系统的基本特点

1. **数据的集成性**：集多种应用数据于一体——采用统一的数据结构、建立全局统一的数据模式、根据每个应用的需要构造局部模式【db01 P31】
2. **数据的高共享性与低冗余性**：共享 = 供多应用使用、可在已有库上开发新应用、可对外提供信息服务；冗余 = 同一数据重复存储；<mark>高共享、低冗余可避免数据的不一致性（同一数据不同拷贝值不同），是保证系统一致性的基础</mark>【db01 P32–33】
3. **数据独立性**：数据与使用数据的应用程序之间的互不依赖性，数据/数据结构的改变无需修改应用程序（反之亦然）——分**物理独立性**与**逻辑独立性**【db01 P34】
   > 课堂比喻：低耦合、高内聚
4. **数据的统一管理与控制**：DBMS 对数据统一管理，提供数据安全、完整性、并发控制与故障恢复等机制【db01 P39】
